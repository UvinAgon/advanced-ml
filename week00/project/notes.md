## Summary of what I learnt

- Defining the logic in the system is exploitation programming, and in AI, it doesn't define the logic and lets it decide on its own.
- A deterministic function gives the exact value as the result.
- For a probabilistic function, it needs to find the mapping function; it uses ML to train the model.
- If the model accuracy gets 100%, it's an overfitting situation. It shouldn't happen.
- ML is a tool to create an algorithm using data and experiences.
- Traditional programming leads to results using given input data and the program, but in the ML approach, using the given data and results leads to the program(the model).
- If a neural network contains 3 or more hidden layers, it's a deep neural network. And training a deep neural network is "Deep learning".
